# Linzecar × QTT — Demo de Integración

Plataforma de inspección vehicular en terreno. Demo interactiva de la propuesta técnica QTT SpA para Linzecar.

## Vistas disponibles

- **Linzecar.cl** — Marketplace con búsqueda IA, catálogo de autos, panel de inspección QTT con selector de fecha y QR de confirmación
- **Soy Linzer** — App móvil del inspector: login, recepción de trabajos, ejecución de los 14 pasos con captura de fotos y documentos
- **QTT Backoffice** — Dashboard de KPIs, transacciones con evidencia fotográfica y documental por paso, gestión de Linzers

## Stack

- React 18 + Vite
- CSS-in-JS (inline styles)
- Sin dependencias externas

## Desarrollo local

```bash
npm install
npm run dev
```

## Deploy

Conectado a Vercel vía GitHub — cada push a `main` redeploya automáticamente.
